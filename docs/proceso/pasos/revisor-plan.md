# Paso del módulo revisor-plan

**En §2 (plan), solo si el issue tiene la etiqueta `critica`.** Escrito el fichero de plan, lanza
el subagente `revisor-plan` con N y la ruta del fichero, y pon su informe tal cual al principio
del plan. No corrijas el plan por tu cuenta: si el veredicto es «dudas», di a Pedro que lo
lleve al chat con solo esas secciones. Si el subagente no existe (se creó a mitad de sesión) o
falla, dilo y presenta el plan sin informe.
