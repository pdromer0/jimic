# JimiC

Agente personal proactivo que acompaña a Pedro durante el día por el móvil, conoce sus objetivos y
le ayuda a cumplirlos con datos reales: a diferencia de un chatbot, escribe primero.

**Estado:** hito 0 (entorno) cerrado, con la etiqueta `v0.0-hito0`. El hito 1 (tiempo y
entrenamiento) empieza con su sesión conceptual. Ver la [hoja de ruta](docs/diseno.md).

- [Diseño](docs/diseno.md): visión, arquitectura, hoja de ruta y registro de decisiones.
- [Documentación](docs/README.md): especificaciones de los hitos, decisiones (ADR), proceso y
  diario.
- [Seguridad](SECURITY.md): cómo avisar de una vulnerabilidad.
- [Privacidad](PRIVACIDAD.md): qué datos de Google lee JimiC y cómo se tratan.

Se construye con el método EDsim v2
([ADR 0001](docs/decisiones/0001-adoptamos-el-metodo-edsim.md)): Pedro decide y fusiona; los
agentes implementan por PR.

Sin licencia por ahora (decisión 53): el código se puede leer, pero no reutilizar.
